---

확인된 대화 내용과 사용자가 원하는 다음 행동을 담아 고객 후속 메일 초안을 작성해 주세요.

입력
- 수신자, 소속과 현재 관계: [필수 또는 역할 표기]
- 발신자와 회사·서비스 설명: [필요한 범위]
- 연락 목적과 상대에게 요청할 다음 행동: [필수]
- 회의록·대화·이전 메일 중 근거 자료: [내용을 확인할 자료]
- 전달할 자료·링크·일정·조건: [사용자가 확정한 내용]
- 언어·어조·분량과 서명: [원하는 형식]
- 외부 공유를 허용한 내용과 별도로 확인할 내용: [관련 내용]

진행 방법
1. 상대방과의 관계, 연락 목적과 요청할 행동을 확인해 주세요. 핵심 입력이 없으면 그 항목을 질문하고 나머지는 확인된 자료로 작성해 주세요. 언어·어조가 없으면 한국어 존댓말의 간결한 업무 메일로 작성해 주세요.
2. 사용자에게 제공받은 근거에서 상대방의 요청, 합의와 남은 일을 추려 주세요. 메일에는 상대방이 다음 행동을 이해하는 데 필요한 내용을 담아 주세요.
3. 제안, 검토와 확정된 합의의 수준을 유지해 주세요. 가격·할인·납기·기능·첨부 파일·링크는 사용자가 확정하거나 자료로 확인된 값만 넣어 주세요. 발송 전에 채워야 하는 내용은 별도 확인 목록에 적어 주세요.
4. 자료의 내부 검토 의견은 사용자에게 보여줄 메모에 담고 고객에게 보낼 본문에는 외부 공유가 허용된 내용을 사용해 주세요. 공유 범위가 모호한 내용은 확인 목록으로 옮겨 주세요.
5. 본문에는 연락한 배경, 필요한 요약, 요청할 다음 행동과 인사를 자연스럽게 연결해 주세요. 상대에게 여러 요청이 있으면 실행 순서가 보이게 정리해 주세요.

결과 형식
- 제목
- 메일 본문
- 사용자 확인 목록: 수신자·전달 자료·일정·약속·공유 범위 중 확인이 필요한 항목

메일 본문과 사용자 확인 메모를 구분해 주세요. 결과는 초안으로 작성하고 실제 발송은 사용자가 명시적으로 요청한 경우에 별도로 진행해 주세요.
