회의 원문을 읽고 논의 결과와 후속 작업을 구분해 정리해 주세요.

입력
- 회의 메모·녹취·대화 기록: [필수]
- 회의명·일시·참석자: [알고 있는 범위]
- 정리에 참고할 이전 기록: [지정한 자료가 있으면 입력]
- 결과를 읽을 사람과 공유 범위: [내부용 회의록 또는 고객 공유용]

진행 방법
1. 입력한 기록의 범위와 회의 일시를 확인해 주세요. 일부 녹취나 발췌본이면 정리 범위에 표시해 주세요. 발언자의 신원이 불명확하면 원문의 화자 표기를 유지해 주세요.
2. 주요 논의, 확정된 결정, 제안과 검토 중인 항목을 나누어 주세요. 회의록 본문에서 발언의 확정 수준과 조건을 보존해 주세요.
3. 각 후속 작업에 작업 내용, 명시된 담당자, 명시된 기한과 완료 조건을 적어 주세요. 자료에 없는 담당자·기한은 확인 필요로 표시해 주세요. 새로 제안하는 작업은 합의된 작업과 구분해 주세요.
4. 상대 날짜는 회의 날짜가 확인될 때 해석하고 원문 표현을 함께 남겨 주세요. 기준 날짜가 모호하면 원문과 확인 필요 표시를 유지해 주세요.
5. 결정과 후속 작업에는 타임스탬프, 원문 위치 또는 근거 발언을 붙여 주세요. 모순되는 발언은 양쪽 근거와 함께 확인할 항목에 남겨 주세요.
6. 고객 공유용 결과에는 공유가 허용된 내용만 담고 전달 범위가 불명확한 내부 메모는 사용자 확인 항목으로 남겨 주세요.

결과 형식
- 회의 정보와 기록 범위
- 주요 논의 요약
- 결정 사항 표: 결정 / 조건 / 근거
- 후속 작업 표: 작업 / 담당자 / 기한 / 완료 조건 / 근거
- 검토 중인 제안과 미결 질문
- 사용자가 확인할 사항

회의 원문이 없으면 필요한 자료를 요청해 주세요. 결과는 회의록과 후속 작업 목록 초안으로 작성해 주세요. 업무 등록이나 메시지 전송은 사용자가 별도로 요청할 때 다뤄 주세요.
