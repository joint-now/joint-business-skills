# 업무별 요청 예시

예제 파일은 모두 가상 자료입니다. 아래 문안을 대화에 붙여넣고 해당 파일을 첨부하세요. 웹 검색이나 서비스 연결 없이 제공 자료만으로 시작할 수 있습니다.

## 고객사 조사

첨부: `company-context.md`, `company-brief.md`

```text
고객사 조사 스킬로 가상회사 새봄제조의 첫 미팅용 브리핑을 작성해 주세요.
우리 회사 설명과 고객사 소개를 첨부했습니다.
외부 검색은 생략하고 첨부 자료만 사용해 주세요.
예산, 구매 결정자와 도입 의지는 자료에서 확인된 수준으로 적어 주세요.
```

## 미팅 준비

첨부: `company-context.md`, `company-brief.md`

```text
가상회사 새봄제조와 요청 접수·담당자 배정 흐름을 알아볼 30분 미팅을 준비해 주세요.
한결오퍼레이션의 서비스 설명과 고객사 소개를 첨부했습니다.
진행안, 우선 질문과 준비물을 작성해 주세요.
```

## 회의 정리

첨부: `meeting-notes.md`

```text
고객 회의 정리 스킬로 첨부 발췌본을 정리해 주세요.
결정, 검토 중인 제안과 후속 작업을 구분하고 각각의 근거를 붙여 주세요.
원문에 없는 담당자와 기한은 확인할 항목으로 남겨 주세요.
```

## 후속 메일

첨부: `meeting-notes.md`

```text
한결오퍼레이션 민지가 새봄제조 도윤에게 보내는 후속 메일을 작성해 주세요.
목적은 데모 전달 계획을 확인하고 시연용 요청 항목 예시를 받는 것입니다.
외부에 전달할 수 있는 근거는 첨부 회의록이며, 정해진 데모 전달 기한은 11월 9일입니다.
가격과 연동 방식은 아직 검토 중인 상태를 유지해 주세요.
한국어 존댓말로 간결하게 작성하고 실제 발송은 진행하지 마세요.
```
